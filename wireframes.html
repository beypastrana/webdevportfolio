Wireframes

Low-fidelity layouts for the four core buyer screens — built to test structure and flow before any visual design, so the layout logic could be validated first.

01 · Marketplace
Veggies
Fruits

Search-first layout — category chips sit above the fold so buyers can filter before scrolling.

02 · Product Detail
Add to Cart

Farmer badge near the top — builds trust by showing who grew it before the buyer even reads the description.

03 · Cart
Checkout

Order summary pinned low — subtotal and checkout button stay reachable by thumb without scrolling far.

04 · Checkout
GCash
COD
Place Order

Payment method as chips — GCash defaulted since it's the most common option for this audience.

Fidelity choices

Kept intentionally grayscale with placeholder blocks instead of real content — the goal at this stage was validating layout, hierarchy, and thumb-reach on mobile, not visual style. Color and branding came later in the mockup phase.

What testing changed

An early version had checkout as a separate multi-page flow; quick usability checks with two farmer-app users showed people expected everything in one screen, so cart and checkout were simplified to fewer, denser steps.
