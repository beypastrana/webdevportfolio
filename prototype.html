Why an interactive prototype

Static mockups can't show how a flow actually feels to use. This clickable version was used to run quick hallway tests with a few farmers and buyers before any code was written, catching confusing steps early and cheaply.

What I'd test next

Whether buyers notice the delivery fee before checkout, and whether "Message" on the product page gets used — if it doesn't, that screen real estate could go to a more common action instead.
